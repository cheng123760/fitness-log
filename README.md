# 健身减脂 · 数据仓库

> 用途：每日热量摄入 / 消耗核算、体重体脂趋势、训练与饮食方案。
> 这个仓库代替本地工作区，作为云端可读写的唯一数据源。

## 读取顺序（每次开场必读）

1. `健身基准卡.md` —— 长期参数：体测、BMR/TDEE、双档摄入、蛋白质依据、训练计划、作息、补剂
2. `每日记录.md` —— 最近的逐日记录（重点看最近 3–7 天）

## 已确定的参数（不要重复询问）

- 男 / 33 岁 / 179 cm / 79.4 kg / 体脂 31.7%
- BMR 1540（Katch-McArdle，由体脂推算）；Mifflin 同参数 1753
- 非训练日 1650 kcal / 训练日 2000 kcal；蛋白质固定 140 g
- 训练：力量 50 min + 有氧 40 min，每周 3 次，有健身房
- 作息：12:30 睡 / 8:30 起
- 饮食：自炊为主；油 ≤25 g/日
- 补剂：一水肌酸 3–5 g/日（每天吃，含休息日）；乳清蛋白按缺口补

## 每日要报的四项

1. 早起空腹体重
2. 吃了什么（按餐报，颗粒度到"两个包子一碗豆浆"即可）
3. 练了什么
4. 有没有漏的（饮料、水果、零食、加餐）

## 更新规则

- 每天在 `每日记录.md` 顶部按日期倒序追加一节
- 超过 30 天的记录归档到 `archive/YYYY-MM.md`
- 报告口径：体重看 7 日滚动均值，不看单日波动
