使用说明（先看这 3 条）

1. 每个动作留 2–3 次余力

一组做到「还能再做 2–3 次，但就此停下」，这叫 RIR 2–3。新手最容易犯的错是数到 12 就停——如果你做到 12 次时还有一半力气，那重量太轻了。

2. 什么时候加重量

同一个重量连续 2 次训练都能做到 12 次 → 加重量（上肢 +2.5 kg、下肢 +5 kg），次数回到 8 次重新爬。
这就是「渐进超负荷」，整套方案里唯一真正驱动效果的东西。

3. 每次必须记下来

记 重量 × 次数 × 组数。这份记录比体重秤重要得多——它是判断「有没有掉肌肉」最灵敏的指标。重量在涨，说明肌肉在，哪怕体重没动。

为什么是 A/B/C 三套而不是一套反复：同一个动作每周做 3 次、连做几个月，肩和腰最容易累积劳损；而且深蹲 / 罗马尼亚硬拉 / 腿举对腿的刺激角度完全不同。三套轮换既是换角度，也是换心情。

热身流程（8 分钟，别省）

顺序内容
1. 升温椭圆机 / 快走 / 划船机 5 分钟，到微微出汗
2. 活动关节髋关节环绕 10 次/侧、肩关节环绕 10 次/向、猫牛式 10 次
3. 第一个动作用空杆或 50% 重量做 2 组 × 10 次递增热身，再上正式组

不要做静态拉伸。训练前静态拉伸会短暂降低力量输出 5–8%，拉伸放在练完或单独一天。

周一 · 全身 A

A

全身 A腿（股四主导）+ 水平推 + 水平拉 + 肩中束 + 核心

  1. 深蹲股四头 / 臀
  2. 卧推胸 / 前三角 / 三头
  3. 坐姿划船背阔 / 中背
  4. 哑铃侧平举肩中束
  5. 卷腹腹直肌
A1
深蹲Back Squat / Goblet Squat
起始姿势

杠铃放在斜方肌上部（高杠位）；双脚与肩同宽，脚尖外展 15–30°；挺胸、核心收紧。

执行
  • 吸气、收紧核心 → 屈髋和屈膝同时进行，不是先屈膝
  • 下蹲过程中膝盖始终沿脚尖方向外推，别内扣
  • 蹲到大腿与地面平行或略低，脚掌三点（大脚趾、小脚趾、脚跟）均匀踩实
  • 呼气站起，髋和膝同步伸展
常见错误
  • 脚跟离地 → 踝背屈活动度不足，临时在脚跟垫 1–2 cm 杠铃片
  • 膝盖内扣 → 主动想「把地面掰开」
  • 下背弯曲（"眨眼"） → 蹲太深了，先练到平行为止
  • 蹲太浅，几乎没下就起
重量 / 替代

空杆 20 kg 起。没有杠铃就做高脚杯深蹲（双手抱一个哑铃或壶铃在胸前，12–16 kg），对新手更友好，学动作更快。

A2
卧推Bench Press
起始姿势
  • 肩胛骨后缩下沉、牢牢贴住凳面（这一步决定肩安全）
  • 双脚踩实地面，臀部不离凳
  • 握距略宽于肩，杠铃下放时前臂应垂直地面
执行
  • 下放到乳头连线位置，肘与躯干夹角约 45–75°（不要 90° 完全外展）
  • 推起时脚蹬地、肩胛保持后缩，胸口略向上顶
  • 顶端不锁死肘关节
常见错误
  • 肩胛前伸（含胸） → 肩关节前侧压力剧增，最常见的肩伤来源
  • 肘部完全外展 90° → 肩峰撞击风险
  • 臀部离凳拱成桥、杠铃弹胸
重量 / 替代

空杆 20 kg 起。没器械就做哑铃卧推（每只 12–16 kg）或标准俯卧撑，效果不打折。

A3
坐姿划船Seated Cable Row
起始姿势

坐稳，脚踩踏板，膝盖微屈；脊柱中立（不弓不塌），手臂伸直但肩不放松。

执行
  • 关键顺序：先收肩胛，再拉手臂。先把肩胛骨向后夹，再让肘部沿身体两侧往后拉
  • 手柄拉到腹部，肘部贴近身体
  • 回放要慢（3 秒），让肩胛骨向前伸展、背阔拉开
常见错误
  • 只用胳膊拉，背部完全没参与 → 你练的是二头不是背
  • 身体前后大幅摆动，用惯性甩
  • 耸肩（斜方肌代偿）
重量 / 替代

20–30 kg 起。新手找感觉可以先做「直臂下拉」，只感受背阔发力。替代：哑铃单臂划船、器械划船。

A4
哑铃侧平举Lateral Raise
起始姿势

站立，哑铃垂于体侧，肘关节微屈 10–15°（保持这个角度不变），上身略前倾。

执行
  • 肘部领先，手在肘之后——像倒水一样，手腕略低于肘
  • 抬到与肩同高就停，不要举过头
  • 下放 3 秒，控制住
常见错误
  • 重量太大靠身体甩上去 → 这个动作几乎所有人都用太重，是最典型的问题
  • 耸肩，变成斜方肌训练
  • 抬过肩高（超过 90° 后中束不再参与）
重量 / 替代

男 4–8 kg/只，宁轻勿重。能做 12 次且完全不甩，就是合适的重量。替代：弹力带侧平举、绳索侧平举。

A5
卷腹Crunch
起始姿势

仰卧，膝屈约 90°，双脚踩地；双手交叉胸前，或轻扶耳侧（不发力）。

执行
  • 呼气时脊柱逐节卷起，只有肩胛骨离地——不是整个上半身坐起来
  • 顶端停 1 秒，感受腹肌挤压
  • 吸气缓慢回落，肩不着地即接下一次
常见错误
  • 手拉脖子 → 颈椎受压
  • 做成完整的仰卧起坐 → 那是屈髋（髂腰肌主导），不是练腹
  • 靠惯性甩起来
组数

3 组 × 12–15 次。核心是小肌群，次数可以略高。

周三 · 全身 B

B

全身 B腿（臀 / 股二主导）+ 垂直推 + 垂直拉 + 二头 + 核心

  1. 罗马尼亚硬拉臀 / 股二头
  2. 坐姿哑铃推肩前三角 / 三头
  3. 高位下拉背阔肌
  4. 哑铃弯举肱二头
  5. 悬垂举腿腹直肌下部
B1
罗马尼亚硬拉Romanian Deadlift
起始姿势

站姿，杠铃/哑铃在体前贴腿；膝关节微屈 15–20°，而且全程这个角度固定不变——这是它和深蹲的根本区别。

执行
  • 核心动作是「髋部向后推」——想象用屁股去关一扇车门
  • 杠铃贴着小腿、大腿下滑，越近越好
  • 下到腘绳肌（大腿后侧）有明显牵拉感为止，一般杠铃过膝到小腿中部
  • 臀部发力向前顶，回到站直，不要过度后仰
常见错误
  • 做成深蹲 → 膝盖弯太多，股四头抢走全部负荷
  • 弓背 → 腰椎风险最大的错误，重量宁轻
  • 杠铃离身体太远（杠杆变长，腰承受翻倍压力）
  • 下太深超过柔韧极限
重量 / 替代

空杆或 40 kg 起。这个动作重量涨得比深蹲快，但千万别贪——它是腰最容易受伤的动作。替代：器械腿弯举、臀桥。

B2
坐姿哑铃推肩Seated Dumbbell Shoulder Press
起始姿势

靠背调到 80–85°（接近直立）；哑铃举到肩两侧，肘在手腕正下方，掌心向前或略相对。

执行
  • 向上推到头几乎伸直，不锁死肘
  • 下放到肘略低于肩，感受三角肌拉长
  • 全程核心收紧，肋骨不要翘起
常见错误
  • 腰过度后仰 → 这个动作就变成了上斜卧推，肩的负荷被偷走
  • 下放太浅（只做四分之一程）
  • 耸肩
重量 / 替代

10–14 kg/只。替代：器械推肩（对新手更安全）、站姿杠铃推举（进阶）。

B3
高位下拉Lat Pulldown
起始姿势

坐稳，大腿卡在固定垫下（防止被拉起来）；握距略宽于肩，正握。

执行
  • 先下沉肩胛，再拉——不要一上手就弯手臂
  • 把横杆拉到锁骨 / 上胸位置，肘部向下向后
  • 回放 3 秒，让背阔完全伸展
常见错误
  • 身体大幅后仰，用体重把杆拉下来（变成划船）
  • 拉到颈后 → 肩关节被迫极度外旋，无收益且伤肩
  • 只用手臂，背部没参与
重量 / 替代

30–40 kg 起。替代：辅助引体向上、器械下拉。

B4
哑铃弯举Dumbbell Curl
起始姿势

站立，哑铃垂于体侧，掌心向前；肘关节固定在身体两侧，这是全程唯一不能动的关节。

执行
  • 只做前臂屈曲，肘不前后移动
  • 顶端稍旋外（小指略高于拇指），二头收缩更充分
  • 下放 3 秒，离心阶段是长肌肉的主要环节
常见错误
  • 甩身体借力
  • 肘部前后移动（变成前平举）
  • 下放太快 → 等于扔掉一半效果
重量 / 替代

8–12 kg/只。替代：杠铃弯举、绳索弯举。

B5
悬垂举腿Hanging Leg Raise
起始姿势

双手握单杠悬垂，肩胛微收（不要完全放松挂着）。

执行
  • 关键是先骨盆后倾，再抬腿——是把骨盆卷起来，不是单纯抬大腿
  • 抬到腿与地面平行或更高，缓慢下放
  • 下放时不要让身体前后摆动
常见错误
  • 只抬大腿不卷骨盆 → 练的是髂腰肌（髋屈肌），不是腹肌。这是这个动作最大的误区
  • 用摆动惯性把腿荡上去
替代

做不动就做屈膝悬垂举腿（膝盖弯着抬）或仰卧举腿，效果一样，门槛低得多。

周六 · 全身 C

C

全身 C腿（器械）+ 上斜推 + 垂直拉（引体）+ 三头 + 核心抗伸展

  1. 腿举股四头 / 臀
  2. 上斜卧推上胸
  3. 辅助引体向上背阔肌
  4. 绳索三头下压肱三头
  5. 平板支撑核心抗伸展
C1
腿举Leg Press
起始姿势

坐进器械，背部和臀部完全贴住靠背；双脚与肩同宽，放在踏板中部（放太高会变成臀主导）。

执行
  • 下放到膝关节约 90°——以腰不离靠背为界限，这是唯一标准
  • 脚掌均匀发力推起，膝盖不锁死
  • 膝盖沿脚尖方向，不内扣
常见错误
  • 下放太深导致骨盆后倾、腰离开靠背 → 腰椎剪切力极大，是这个器械最主要的受伤方式
  • 膝盖内扣
  • 顶端锁死膝关节
重量 / 替代

以器械刻度为准，从能标准完成 12 次的重量起。替代：哈克深蹲、高脚杯深蹲。

C2
上斜卧推Incline Bench Press
起始姿势

凳角 30–45°；超过 45° 就变成推肩了，上胸的刺激反而减少。其余同平卧推（肩胛后缩下沉）。

执行

杠铃下放到锁骨下方 / 上胸位置，推起路径略向后上（不是垂直向上）。

常见错误
  • 角度调太高（>45°）
  • 下放位置太靠下（变成平卧推）
  • 肩胛前伸
重量

比平卧推轻 10–20%，这是正常的，不要以为自己退步了。替代：上斜哑铃卧推。

C3
辅助引体向上Assisted Pull-up
起始姿势

辅助器械（配重块托膝）或长弹力带辅助；握距略宽于肩，掌心朝前。

执行
  • 先下沉肩胛，再开始弯臂
  • 肘部向身体两侧下方拉，拉到下巴过杆
  • 下放 3 秒——离心阶段是引体增长力量最快的部分
常见错误
  • 耸肩起（斜方代偿）
  • 只做上半程
  • 辅助重量设错：做不动就加辅助，做太轻松就减辅助，目标是「刚好能做 8–12 次」
进阶路径

辅助重量逐步减少 → 最终做自重引体。这是唯一一个以「减少配重」为进步的器械，别记成加重量。替代：高位下拉。

C4
绳索三头下压Triceps Pushdown
起始姿势

站在绳索机前，肘关节紧贴体侧固定，前臂约 90°，上身略前倾。

执行
  • 只有前臂在动，把绳索下压到底
  • 底端两手略向外分开，顶端停 1 秒
  • 回放 3 秒到 90°
常见错误
  • 肘部前后摆动（变成划船或下压混合）
  • 身体前倾用体重压下去
  • 上臂不固定
重量 / 替代

20–30 kg。替代：哑铃颈后臂屈伸、窄距俯卧撑。

C5
平板支撑Plank
起始姿势

前臂撑地，肘在肩正下方；双脚略分开（比并拢稳）。

执行
  • 三个收紧同时做：骨盆后倾 + 臀部夹紧 + 腹肌收紧
  • 身体从肩到脚踝一条直线，正常呼吸不憋气
  • 30–45 秒为准，超过 60 秒收益急剧递减
常见错误
  • 塌腰 → 最常见，此时腰椎在承压，立刻停
  • 撅臀（省力做法，等于没练）
  • 憋气
组数

3 组 × 30–45 秒。能做 2 分钟不代表核心强，只代表你换了更省力的姿势。想进阶就做单臂单腿的变式，不是延长时间。

每次训练只需要记住三件事：
1. 上次这个动作做了多重、做了几次？
2. 今天能不能多做 1 次，或者加 2.5 kg？
3. 每个动作留 2–3 次余力收工。

其他都不重要。动作好看、组数多、练得累——都不如「重量每周在涨」这一条。你现在在热量缺口里练，力量能保持住甚至小涨，就说明肌肉没掉。
明天（10/28 周三）第一次就做 A。之后 周六 B、下周一 C、下周三 A。
第一个月重量宁轻勿重，目标是让动作定型、让身体适应，不是把力气用光。第 3–4 周开始你自然会想加重量，那时候再加。
